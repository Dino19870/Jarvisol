# Rapports d'Audit et de Qualification Technique (Jarvisol)

Ce dossier regroupe les rapports d'audit, de traçabilité et de tests de non-régression (TNR) générés lors des différentes phases de stabilisation, de validation et de qualification technique de Jarvisol (Vagues A, B, C, audits post-gel, qualification Web Media, et inventaires d'intégrité SHA-256).

Ces fichiers servent d'archive de traçabilité historique et ne sont pas nécessaires à la compilation ni à l'exécution du code source.
