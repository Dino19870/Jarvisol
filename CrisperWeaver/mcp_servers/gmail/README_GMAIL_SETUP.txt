=== JARVISOL GMAIL MCP SERVER CONFIGURATION ===

Pour activer l'intégration Gmail MCP :
1. Obtenez vos clés OAuth client Google Cloud (Desktop Application) depuis la console GCP :
   https://console.cloud.google.com/apis/credentials
2. Renseignez votre client_id et client_secret dans "gcp-oauth.keys.json" (ou copiez votre fichier GCP OAuth).
3. Exécutez "LOGIN_GMAIL.bat" pour vous authentifier via votre navigateur.
4. Le fichier "credentials.json" sera automatiquement créé avec votre session sécurisée.
